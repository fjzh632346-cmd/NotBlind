## 更新内容

- 软件内自动更新：发现新版会在后台下载（优先走国内加速线路，某条失败自动换下一条），下完后右上角更新图标显示「重启并更新」。
- 下载完会用 GitHub 上的校验码核对安装包，对不上就丢弃、不会安装。
- 差量更新：以后只下载新旧版本之间变化的部分。
- 3.0 / 3.1 的用户需要手动下载安装一次本版本（下面的 NotBlind-3.1.1-Setup.exe），之后都会自动更新。
